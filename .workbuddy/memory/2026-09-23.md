## 追加：布局选型稿（4 选 1）+ 按钮动效（仍为预览稿，未改正式代码）

用户反馈：视觉可以了，**布局仍不满意**；另要求**按钮要有动态感**；要求先给几个布局让他选。

### 四套布局（同一份 DOM，靠 `body[data-l]` 切 grid 排布）
1. **剧院式**：830 窄中栏一路到底 + Hero 居中 + 无侧栏 → 最贴"树洞"气质，移动端与现状一致
2. **瀑布式**：Hero 左 + 精选右；公告/回声/数据三栏条 + 公约通栏；帖子双列 → 浏览效率最高
3. **App 式**：左侧固定导航（广场/发布/消息/我的 + 带数的分类列表）+ 中栏单列 + 右栏模块 → 功能变多后最好用
4. **Bento 头版**：Hero(3列) + 精选(1列)；4 格宫格（公告 2×2 / 回声 / 数据 / 公约 2×1）；正文回到 840 居中 → 最"设计感"

### 按钮动效（5 层叠加，会落到 main.css 全局）
磁吸（位移系数 0.2 / 文字 0.08）+ 聚光跟随（radial-gradient + --mx/--my）+ 涟漪（pointerdown 建 span，700ms 移除）+ 悬浮扫光 & 箭头右移 4px + 按下回弹（--ps: .955）
- 关键实现：位移走 CSS 变量 `--tx/--ty/--lx/--ly/--ps`，最后合成**同一个 transform**，否则磁吸和按下缩放会互相覆盖
- 触摸设备（`hover: none`）不启用磁吸；`prefers-reduced-motion` 全部关闭

### 踩坑（★ 值得记住）
- **`data-L` 写成大写会在 JS 里彻底失效**：HTML 属性名统一小写，`element.dataset.L` 读不到；而 `dataset.L = x` 会写出 `data--l`，CSS `body[data-l="2"]` 永远匹配不上。表现是"切布局毫无反应、看着像没生效"。**一律用全小写 `data-l` + `getAttribute('data-l')`**
- 4 套布局共用一份 DOM 比写 4 份 markup 省太多：grid-template-columns + grid-column/row 显式定位即可；`@media` 里逐个降级成单列
