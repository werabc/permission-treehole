### 关键实现点
- 顶栏：浮动玻璃胶囊 + sticky，`dh-hdr::before` 做渐变遮罩防止滚动时文字穿透
- 移动端：`dh-only-mobile` / `dh-hide-mobile` —— 窄屏把主题/设置/退出收进「更多」下拉，否则顶栏必然横向溢出（实测溢出 39px）
- 登录/注册页 `meta.guest` → App 隐藏顶栏与页脚，实现整屏分屏
- 首页「今日回声」用列表里 content 最长的一条真实帖子，不造假数据；统计只用真实总数（心事数/分类数）
- 公告轮播改用 JS 计时 + Vue Transition（原 CSS 百分比关键帧按 N 条写死，N≠3 会串帧）

### 本轮发现并修复的真实缺陷
1. **未登录点赞会把人登出并弹回登录页**：点抱抱 → 接口 401 → axios 拦截器 `logout()` + 跳 /login。已在 `handleLike` / `handleCommentLike` 加登录前置引导（与 `handleCollect` 一致）
2. **非数字路由 id 打成 500**：`/post/abc` → `Number(route.params.id)`=NaN → `GET /api/th/post/NaN` → `MethodArgumentTypeMismatchException`。PostDetail 与 UserProfile 均加 `Number.isInteger && >0` 守卫，非法时给友好空态
3. **移动端顶栏横向溢出 39px**（已用「更多」菜单解决）
