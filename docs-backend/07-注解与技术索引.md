## 一、Spring 核心注解

| 注解 | 使用位置 | 作用 |
|------|---------|------|
| `@SpringBootApplication` | `PermissionApplication` | 启动类（组合了 @Configuration + @ComponentScan + @EnableAutoConfiguration） |
| `@Configuration` | `MyBatisPlusConfig`, `RedisConfig`, `SecurityConfig`, `WebMvcConfig` | 声明配置类 |
| `@Bean` | 各 Config 类方法 | 声明 Spring Bean |
| `@Component` | `JwtAuthenticationFilter`, `SecurityAccessDeniedHandler`, `SecurityAuthenticationEntryPoint`, `DataInitializer`, `OperationLogAspect` | 通用组件扫描 |
| `@Service` | `SysUserServiceImpl`, `SysRoleServiceImpl`, `SysMenuServiceImpl`, `SysDeptServiceImpl`, `SysOperationLogServiceImpl`, `SysLoginLogServiceImpl`, `UserDetailsServiceImpl` | 业务层组件 |
| `@Mapper` | 所有 Mapper 接口 | MyBatis 映射接口 |
| `@MapperScan("com.permission.system.mapper")` | `MyBatisPlusConfig` | 扫描 Mapper 包 |
| `@Autowired`（隐含） | — | 本项目使用构造器注入替代 |
| `@RequiredArgsConstructor` | 所有 Service/Controller/Filter/Handler | Lombok 生成构造器，配合 `final` 字段实现构造器注入 |
| `@EnableTransactionManagement` | `MyBatisPlusConfig` | 启用 `@Transactional` |
| `@Transactional` | Service 的写操作方法 | 声明式事务 |
| `@EnableWebSecurity` | `SecurityConfig` | 启用 Web 安全 |
| `@EnableMethodSecurity` | `SecurityConfig` | 启用方法级安全（@PreAuthorize） |
| `@SpringBootApplication` → `@ComponentScan` | 启动类 | 自动扫描 `com.permission` 下所有组件 |

## 三、MyBatis-Plus 注解

| 注解 | 使用位置 | 作用 |
|------|---------|------|
| `@TableName("xxx")` | 所有实体类 | 指定数据库表名 |
| `@TableId(type = IdType.AUTO)` | `BaseEntity.id`, `SysLoginLog.id`, `SysOperationLog.id` | 主键自增 |
| `@TableField(fill = FieldFill.INSERT)` | `BaseEntity.createTime`, `BaseEntity.deleted` | 插入时自动填充 |
| `@TableField(fill = FieldFill.INSERT_UPDATE)` | `BaseEntity.updateTime` | 插入和更新时自动填充 |
| `@TableLogic` | `BaseEntity.deleted` | 逻辑删除标记 |
| `@TableField(exist = false)` | 树形 children、deptName、dataScopeName 等 | 非数据库字段 |
| `@Select("SQL")` | `SysUserMapper`, `SysMenuMapper` | 内联 SQL |
| `@Param("param")` | Mapper 方法参数 | SQL 参数绑定 |
| `extends BaseMapper<T>` | 所有 Mapper 接口 | 通用 CRUD |
| `extends IService<T>` | 所有 Service 接口 | 通用 Service |
| `extends ServiceImpl<M, T>` | 所有 Service Impl | 通用 Service 实现 |

### MyBatis-Plus 拦截器
| 拦截器 | 作用 |
|--------|------|
| `PaginationInnerInterceptor(DbType.MYSQL)` | 自动分页 |
| `BlockAttackInnerInterceptor` | 防全表更新/删除 |
| `MetaObjectHandler` | 自动填充审计字段 |

## 十二、RBAC 权限模型

### 12.1 模型结构
```
用户 (User) ←→ 角色 (Role) ←→ 菜单 (Menu)
                    ↓
              权限标识 (permission)
```

### 12.2 权限校验流程
1. 用户登录 → 加载所有角色编码 + 权限标识 → 放入 `LoginUser`
2. 请求到达 → `JwtAuthenticationFilter` 设置 `SecurityContext`
3. `@PreAuthorize("hasAnyAuthority('system:user:add', 'admin')")` 校验
4. 匹配 `LoginUser.getAuthorities()` 中的 `SimpleGrantedAuthority`

### 12.3 权限标识设计
```
模块:操作:类型

system:user:list       — 用户列表
system:user:query      — 用户查询
system:user:add        — 用户新增
system:user:edit       — 用户编辑
system:user:delete     — 用户删除
system:user:reset-pwd  — 重置密码

system:role:list       — 角色列表
system:role:query      — 角色查询
system:role:add        — 角色新增
...

admin                  — 角色编码，超级管理员绕过所有权限
```

## 十三、安全机制清单

| 机制 | 实现方式 | 关键代码 |
|------|---------|---------|
| **密码加密** | BCrypt | `BCryptPasswordEncoder` |
| **JWT 认证** | HS256 双 Token | `JwtTokenProvider` |
| **Token 黑名单** | Redis | `logout()` 方法 |
| **登录限流** | Redis 计数器 | `login()` 第 1 步 |
| **账户锁定** | Redis 计数器 | `login()` 第 3 步 |
| **验证码** | Hutool LineCaptcha + Redis | `AuthController.captcha()` |
| **密码强度** | 正则表达式 | `PASSWORD_PATTERN` |
| **方法级权限** | `@PreAuthorize` | Controller 方法 |
| **CSRF 防护** | 禁用（无状态 JWT） | `SecurityConfig` |
| **CORS 跨域** | WebMvcConfigurer | `WebMvcConfig` |
| **逻辑删除** | `@TableLogic` | `BaseEntity.deleted` |
| **SQL 注入防护** | MyBatis 参数绑定 | `#{param}` |
| **防全表更新** | `BlockAttackInnerInterceptor` | `MyBatisPlusConfig` |
