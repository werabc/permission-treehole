> **项目名称**：Permission Admin（企业级权限管理系统）  
> **版本**：1.0.0  
> **JDK**：17  
> **Spring Boot**：3.2.5  
> **Spring Security**：6.2.4  
> **构建工具**：Maven（多模块）  
> **文档生成时间**：2026-07-15

---

## 一、项目简介

本项目是一个**企业级 RBAC（基于角色的访问控制）权限管理后端系统**，采用经典的多模块 Maven 架构，实现了用户、角色、菜单、部门、日志等核心权限管理功能。系统提供基于 JWT 的无状态认证、接口级权限控制、操作日志审计、登录安全防御（验证码、限流、账户锁定）等能力。

## 三、模块架构（Maven 多模块）

```
permission-admin (父 POM, packaging=pom)
├── permission-common    — 公共模块：实体、DTO、枚举、异常、常量、通用响应
├── permission-framework — 框架模块：安全配置、JWT、AOP、全局处理器、Redis
├── permission-system    — 业务模块：Mapper、Service、业务实现、切面、数据初始化
└── permission-api       — 启动模块：Controller、应用入口、配置文件
```

### 模块依赖关系

```
permission-api
    └── permission-system
            ├── permission-common
            └── permission-framework
                    └── permission-common
```

- **permission-api** 依赖 **permission-system**（最终装配）
- **permission-system** 依赖 **permission-common** + **permission-framework**
- **permission-framework** 依赖 **permission-common**

## 五、核心功能清单

### 5.1 认证模块（Auth）
- ✅ 图形验证码（Hutool LineCaptcha，Redis 存储 5 分钟）
- ✅ 用户登录（用户名 + 密码 + 可选验证码）
- ✅ 登录限流（IP 维度，60 秒内最多 5 次）
- ✅ 账户临时锁定（连续失败 5 次锁定 30 分钟）
- ✅ 双 Token 机制（Access Token 2h + Refresh Token 7d）
- ✅ Token 黑名单（退出登录时加入 Redis 黑名单）
- ✅ 获取当前用户信息

### 5.2 用户管理（User）
- ✅ 分页查询（关键字模糊搜索 + 部门筛选 + 状态筛选）
- ✅ 新增/修改/删除用户
- ✅ 修改用户状态（启用/禁用）
- ✅ 重置密码 / 修改个人密码
- ✅ 分配角色
- ✅ 密码强度校验（正则：8 位以上，大小写 + 数字 + 特殊字符）

### 5.3 角色管理（Role）
- ✅ 分页查询
- ✅ 新增/修改/删除角色（删除前检查是否已分配用户）
- ✅ 角色名称/编码唯一性校验
- ✅ 分配菜单权限
- ✅ 获取所有角色（下拉框）

### 5.4 菜单管理（Menu）
- ✅ 菜单树查询（递归构建树形结构）
- ✅ 用户菜单查询（动态路由）
- ✅ 菜单名称唯一性校验（同级不重复）
- ✅ 删除前检查子菜单

### 5.5 部门管理（Dept）
- ✅ 部门树查询
- ✅ 祖级列表（ancestors）自动生成
- ✅ 删除前检查子部门和用户

### 5.6 日志管理（Log）
- ✅ 操作日志分页查询（AOP 切面自动记录）
- ✅ 登录日志分页查询
- ✅ 登录日志自动记录

### 5.7 安全特性
- ✅ 接口级权限控制（`@PreAuthorize`）
- ✅ 全局异常处理（`@RestControllerAdvice`）
- ✅ 逻辑删除（`@TableLogic`）
- ✅ 自动填充创建/更新时间（MetaObjectHandler）
- ✅ 分页防全表更新拦截（BlockAttackInnerInterceptor）
- ✅ CORS 跨域配置
- ✅ Swagger / Knife4j 接口文档

## 六、请求处理流程

```
客户端请求
    │
    ▼
CORS 过滤器 (WebMvcConfig)
    │
    ▼
Spring Security 过滤器链
    ├── 放行: /api/auth/login, /api/auth/refresh, /api/auth/captcha, /doc.html, /swagger-ui/**
    └── 其他: 需要认证
    │
    ▼
JwtAuthenticationFilter (OncePerRequestFilter)
    ├── 从 Header 解析 Bearer Token
    ├── 检查 Redis 黑名单
    ├── 验证 JWT 签名与有效期
    ├── 从数据库加载用户权限信息
    └── 设置 SecurityContext
    │
    ▼
@PreAuthorize 方法级权限校验
    │
    ▼
Controller → Service → Mapper → DB
    │
    ▼
OperationLogAspect (AOP @Around) — 自动记录操作日志
    │
    ▼
GlobalExceptionHandler — 统一异常处理
    │
    ▼
R<T> 统一响应格式返回
```

---

## 七、统一响应格式

```json
{
  "code": 200,
    "message": "操作成功",
    "data": { ... }
}
```

- 成功：`code = 200`
- 业务错误：`code` 见 `ResultCode` 枚举（1001~5002）
- HTTP 状态码始终为 200，错误信息通过 `code` 区分
