v3 改动说明

针对你提的四点，逐条给方案。

1 · 白天模式：不再是一张白纸

原来的问题：72px 深灰网格铺满整屏（就是你看到的"格子"）+ 极光图被压成灰调 + 全是白卡片 → 单调且廉价。
新方案：删掉网格，改为三层叠加——① 晨光色彩带（薄荷 / 丁香 / 蜜桃三色 conic 渐变模糊）；② 柔光雾团（慢速漂移）； ③ 暖白基底 + 极细噪点。卡片改为半透白 + 带色彩倾向的投影，顶部加一道渐变细线，避免"白纸感"。

暖白底#F7F6F2
薄荷雾rgba(96,196,168,.42)
丁香雾rgba(168,146,232,.40)
蜜桃雾rgba(240,184,140,.40)
主强调（加深）#0E8F70
正文（暖黑）#1A1916

2 · 黑夜模式：星空感加强

图层做法效果
远星 220 颗半径 0.25–0.72，极慢上浮，微闪铺底，密而不抢
中星 100 颗半径 0.7–1.35，闪烁幅度加大明显"呼吸"
近星 32 颗半径 1.4–2.4 + shadowBlur 发光少量高亮星，有光学感
流星每 5–13 秒随机一颗，带渐隐拖尾偶尔抬头看见流星
视差滚动时三层按不同系数位移（0.02 / 0.05 / 0.09）有纵深，不像贴纸
星云 + 银河带3 团模糊光斑缓慢漂移 + 一条倾斜极淡光带替代原网格，撑起体积感
性能：全部画在一个 canvas 上，共约 350 个粒子 + 偶尔一颗流星；页面不可见时暂停 rAF。 尊重 prefers-reduced-motion（动效关闭时整个星空调成静态或隐藏）。

3 · 布局：把"条形堆叠"改成"内容列 + 侧栏"

原来：公告条 → 全屏搜索框 → 分类条 → 帖子流，四个满宽横条依次堆叠，像把工具栏倒在一张纸上； 且帖子正文栏宽 1132px，中文一行 60+ 字，读起来很累。
新方案（布局 A，推荐）：搜索并入 Hero；公告收进右侧栏做成可展开的手风琴；内容列限定 784px，中文一行约 43 字， 可读性回到正常区间；侧栏放公告 + 树洞公约（含站点数据），滚动时吸顶跟随——只放不与别处重复的信息，不堆卡片凑数。

同时也做了布局 B（顶部三条横幅 + 帖子双列），点上方「布局」可切换对比。我的建议是 A——正文阅读和层次都更好；B 更"杂志感"但双列会打乱浏览节奏。

4 · 功能：能做的做了，做不了的说明白

项状态说明
分类筛选写入 URL要做切分类同步 ?category=，可分享可后退；/category/:code 统一 302 到首页筛选，去掉两套重复入口
触底自动加载要做IntersectionObserver 哨兵，保留「加载更多」按钮兜底
回到顶部要做滚动超过两屏出现
公告手风琴要做用已返回的 content 就地展开，不需要新接口
分类显示帖子数要做接口已返回 postCount，直接展示
今日回声可点击要做跳转到对应帖子
置顶帖独立成"精选卡"要做第一页把 isTop=1 的抽出来单独展示，避免和普通帖混在一起
按 / 聚焦搜索要做键盘快捷
按热度排序不做接口只有 pageNum/pageSize/categoryId/keyword，没有排序参数，加按钮就是假功能
列表显示"我已抱抱/已收藏"不做列表接口不返回当前用户状态；逐条查询会打出 N 个请求
今夜在线人数不做没有对应接口，不想在首页放编造的数字

5 · 管理端（按你说的：先不动）

管理端 permission-ui 我只做思考、不碰 UI。初步判断：它是 Element Plus 的重后台， 和 C 端强行统一视觉意义不大；更值得做的是把 C 端的深色 token 抽成一份共享 CSS 变量， 让管理端只换主题色与卡片圆角，其余保持 Element Plus 原样——这样两边"同族但不同用途"，成本也最低。 要不要动、什么时候动，等你说了再排。
