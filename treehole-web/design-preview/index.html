动效语言

  • 01入场：卡片进入视口时 26px 上浮 + 淡入，逐条延迟 70ms（stagger）。
  • 02悬浮：卡片上浮 4px、边框透出极光青、一道柔光从左掠过。
  • 03背景：极光树缓慢推移（40s ken-burns）+ 星点微闪 + 24s 呼吸。
  • 04触感：按钮按下 scale(0.975)，弹簧缓动 cubic-bezier(.34,1.4,.64,1)。
  • 05无障碍：全站尊重 prefers-reduced-motion，关闭动效与星点。

本次改造要点（相对旧版）

  • A去掉 emoji 图标，全部换成统一线性 SVG 图标（原 🌳🔔⚙️👤 观感廉价）。
  • B深色沉浸式主题替代原来的浅蓝渐变卡片，配极光树背景图，建立记忆点。
  • C玻璃拟态 + 单一强调色，信息层级靠留白与透明度，而非堆边框阴影。
  • D登录页改为左右分屏，左图为情绪画面，右为表单，提升首访质感。
  • E微交互：悬浮露出操作、加载扫码感、数字用等宽字体跳动。
技术落地方式：以上均为纯 CSS + 少量 JS（IntersectionObserver / 星点 canvas），不引入 Three.js 等重库，不增加构建负担；背景图为单张 ~230KB JPG，可随路由懒加载。确认方案后再逐页迁移到 Vue 组件。
